# Deadband twin: what does a linear twin get wrong about an actuator with a dead zone, and does fitting it well fix the controller?

Pure Python, no dependencies. The real actuator applies `D(u) = u − δ·sgn(u)` for `|u| > δ` and nothing inside the dead zone; the plant is `x' = x + b·D(u)`. The twin is linear, `x' = x + g·u`, and `g` is fitted by least squares from Gaussian-dither logs. By Bussgang/Stein the fit converges to `b·P(|u|>δ)`, a function of how hard the logs excited the actuator, not a property of the actuator (0.0455 / 0.3173 / 0.6171 / 0.8026 predicted vs 0.0455 / 0.3176 / 0.6170 / 0.8025 simulated at σ/δ = 0.5 / 1 / 2 / 4). A proportional loop designed in that twin (`K = c/g`, twin predicts error `0.5^k → 0`) has real loop gain `m = bK = c/P`. For `m < 1` the real error approaches the dead-zone edge `δ/K` and never reaches zero (0.101 / 0.123 / 0.160 at σ/δ = 1.5 / 2 / 4, exactly `δ/K`); for `1 < m < 2` it alternates and stops inside the zone; for `m > 2` the map `|e'| = (m−1)|e| − bδ` has a repelling magnitude `bδ/(m−2)`, so instability is a basin, not global (m = 2.5: e₀ = 0.19 settles, e₀ = 0.21 blows up; a twin fitted at σ = 0.5δ gives m = 11 and diverges from e₀ = 1). Inverse-deadband compensation with a fitted `δ̂` is asymmetric and exact: under-compensating by `|Δ|` leaves a floor `|Δ|/K`, over-compensating chatters in a 2-cycle of amplitude `bΔ/(2−m)`, 3× smaller for the same `|Δ|` at `m = 0.5`. Fitting `(b, δ)` by profile least squares recovers `δ` to 4.9% / 2.5% / 0.8% RMSE at n = 100 / 400 / 1600 and cuts the real steady error from 0.20 (honest-gain P loop) to 0.0046 / 0.0016 / 0.0001. See `paper/whitepaper.md`.

**Builds on.** The digital-twin simulation-fidelity and sim-to-real direction of ARPG (<https://arpg.colorado.edu/>) and the Autonomous Systems IRT (<https://www.colorado.edu/irt/autonomous-systems/>); no specific paper from those groups is reproduced and nothing here is affiliated with or endorsed by them. The gain law is Bussgang's theorem (Bussgang 1952) via Stein's lemma; the compensation is classical inverse-deadband control (Tao & Kokotović 1996). Companion to `control-twin` (wrong linear actuator gain), `saturation-twin` and `quantization-twin` in this repository, which treat other actuator nonlinearities; here the wrong gain is derived from the identification excitation.

Stylised: scalar velocity-commanded plant, symmetric static deadband, Gaussian i.i.d. dither, noise-free state in the loop, a simulated "real" system; the δ grid contains the true value (0.005 steps), which flatters the fit; no field data. MIT.
