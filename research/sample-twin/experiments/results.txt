Sample twin: unit mass, PD control sampled every T and held (ZOH), kp = wn^2, kd = 2 zeta wn. Twin: continuous control.
eps = wn T.  Real loop stable iff kp T/2 < kd < 2/T, i.e. eps < min(4 zeta, 1/zeta).  T = 1 throughout unless stated (time scaling).

== 2. A hard cap for every damping: wn T < 2 (kp T^2 < 4); random search ==
kp T^2 < 4: 44808 stable of 134797 draws; kp T^2 >= 4: 0 stable of 65203 draws
cap in frequency: wn < 2/T = omega_s / pi (omega_s = 2 pi / T); f_n < f_s / pi = 0.318 f_s; attained only at zeta = 1/2
